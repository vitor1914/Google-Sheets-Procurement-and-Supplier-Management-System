# Google Sheets Procurement and Supplier Management System

🇧🇷 **Português** | 🇺🇸 **English**

## 🇧🇷 Português

### Sobre o Projeto

O **Google Sheets Procurement and Supplier Management System** é um sistema de gestão de compras e fornecedores desenvolvido com Google Sheets e Google Apps Script. O projeto busca centralizar informações, automatizar cálculos e facilitar o acompanhamento de pedidos, pagamentos, produtos e requisições de compra.

### Funcionalidades

- **Dashboard:** indicadores de desempenho e gráficos para acompanhamento das compras.
- **Fornecedores:** cadastro e gerenciamento de fornecedores.
- **Produtos:** organização e controle dos produtos cadastrados.
- **Pedidos de Compra:** registro e acompanhamento dos pedidos.
- **Itens dos Pedidos:** detalhamento dos produtos, quantidades e valores.
- **Pagamentos:** controle dos pagamentos relacionados às compras.
- **Requisições:** registro e acompanhamento das solicitações de compra.
- **Automação:** atualização de indicadores e recálculo automático de totais por meio do Google Apps Script.
- **Validação de Dados:** listas suspensas para padronizar os registros.

### Tecnologias Utilizadas

- Google Sheets
- Google Apps Script
- JavaScript
- Fórmulas e gráficos de planilhas

### Objetivos de Aprendizado

- Automatização de processos administrativos.
- Organização e relacionamento de dados.
- Desenvolvimento de dashboards gerenciais.
- Aplicação de lógica de programação em rotinas de negócios.
- Criação de ferramentas para controle de compras e fornecedores.

### Como Utilizar

1. Crie uma planilha no Google Sheets.
2. Acesse **Extensões → Apps Script**.
3. Cole o código-fonte do sistema no editor.
4. Salve o projeto e execute a função de criação do sistema.
5. Autorize as permissões solicitadas pelo Google.
6. Preencha as abas com seus dados e utilize o menu do sistema para atualizar o dashboard.

**Atenção:** a função de criação pode limpar dados existentes nas abas operacionais. Faça uma cópia de segurança antes de executá-la novamente.

### Resultados Esperados

Uma estrutura centralizada para organizar fornecedores, produtos, pedidos, pagamentos e requisições, com indicadores visuais que apoiam o acompanhamento das operações de compras.

## 🇺🇸 English

### About the Project

The **Google Sheets Procurement and Supplier Management System** is a procurement and supplier management solution built with Google Sheets and Google Apps Script. It aims to centralize information, automate calculations, and simplify the tracking of purchase orders, payments, products, and purchase requests.

### Features

- **Dashboard:** performance indicators and charts for procurement monitoring.
- **Suppliers:** supplier registration and management.
- **Products:** organization and tracking of registered products.
- **Purchase Orders:** purchase order registration and tracking.
- **Order Items:** detailed product, quantity, and pricing information.
- **Payments:** tracking of purchase-related payments.
- **Purchase Requests:** registration and monitoring of purchase requests.
- **Automation:** automatic indicator updates and total recalculation using Google Apps Script.
- **Data Validation:** dropdown lists to standardize records.

### Technologies Used

- Google Sheets
- Google Apps Script
- JavaScript
- Spreadsheet formulas and charts

### Learning Objectives

- Automating administrative processes.
- Organizing and relating business data.
- Developing management dashboards.
- Applying programming logic to business workflows.
- Building tools for procurement and supplier control.

### How to Use

1. Create a spreadsheet in Google Sheets.
2. Open **Extensions → Apps Script**.
3. Paste the system's source code into the editor.
4. Save the project and run the system creation function.
5. Authorize the permissions requested by Google.
6. Populate the tabs with your data and use the system menu to refresh the dashboard.

**Important:** the creation function may clear existing data in operational tabs. Back up your spreadsheet before running it again.

### Expected Outcomes

A centralized structure for managing suppliers, products, purchase orders, payments, and purchase requests, supported by visual indicators that help monitor procurement operations.
